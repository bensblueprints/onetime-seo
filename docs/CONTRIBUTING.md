# Contributing

This repository is [`bensblueprints/onetime-seo`](https://github.com/bensblueprints/onetime-seo), the home of **OneTime SEO**. It is a fork of [`every-app/open-seo`](https://github.com/every-app/open-seo), used and redistributed under the MIT license with attribution to the original authors.

## Where to contribute

- **Core product changes** (features, bug fixes, UX improvements to the app itself): contribute upstream to [`every-app/open-seo`](https://github.com/every-app/open-seo), where the original project is developed. This fork periodically syncs from upstream.
- **OneTime SEO product issues** (the hosted app at [seo.onetimesuite.com](https://seo.onetimesuite.com), purchases, Whop sign-in, billing): email [support@onetimesuite.com](mailto:support@onetimesuite.com) instead of opening an issue here or upstream.

## Local development

See [LOCAL_DEVELOPMENT.md](./LOCAL_DEVELOPMENT.md) for how to run the app locally.

## Guidelines

- Keep PRs focused: one feature or fix per PR.
- For larger features, open an issue first so the approach can be agreed on before you invest time.
- Make sure `pnpm ci:check` passes before requesting review.
